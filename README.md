# Dancing Woman

An animated dancer drawn with the HTML Canvas API and plain JavaScript. No libraries, no build step.

## Features
- Three dance styles: Sway, Bounce, Spin
- Tempo slider and pause/play
- Respects the "reduce motion" setting (starts paused)

## Run it
Open `index.html` in any browser.

## How it works
The dancer is a simple skeleton. Each limb is two connected segments, and sine waves drive the angles of the arms, legs, hips and ponytail. Each dance style changes how big those movements are.
